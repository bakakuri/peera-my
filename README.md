# Peera.My — 3D PNG Frontend Redesign

**ვერსია:** UI redesign 2.0 (2026-11-27)

ეს არის `peera-my.zip` პროექტის განახლებული, mobile-first ფრონტენდი. ძირითადი HTML/CSS/Vanilla JavaScript ლოგიკა შენარჩუნებულია. ახალი ვიზუალი ეფუძნება Peera.My-ის ფერად 3D მაკეტებს: იისფერი გრადიენტები, მინისებრი ფენები, მოცულობითი ჩრდილები, PNG ილუსტრაციები და მოძრავი კომპონენტები.

## გაშვება Termux-ში

1. დააყენე `python` და `unzip` საჭიროების შემთხვევაში: `pkg install python unzip`
2. გაშალე ZIP და გადადი საქაღალდეში `peera-my/`.
3. გაუშვი: `python -m http.server 8080`
4. გახსენი ბრაუზერში: `http://127.0.0.1:8080`

> არ გახსნა `index.html` პირდაპირ `file://` მისამართით — ES Modules და `fetch()` ადგილობრივ HTTP სერვერს მოითხოვს.

## რა შეიცვალა

- 20 არსებული WebP კომპონენტი გადაყვანილია PNG-ში, მათ შორის გამჭვირვალე პერსონაჟები, ღილაკები, დეკორაციები და ლოგო.
- შეიქმნა PNG-ფორმატის დამატებითი იკონების ნაკრები `assets/icons/`-ში.
- დამატებულია ხუთი დამოუკიდებელი CSS ფაილი დიზაინისთვის (`redesign-*`).
- დამატებულია მობილური, პლანშეტისა და desktop განლაგება; გაუქმებულია ძველი 430px მაქსიმალური სიგანის შეზღუდვა.
- გაუმჯობესებულია header, navigation, cards, lesson roadmap, dictionary, progress, achievements და auth/admin ვიზუალი.
- პროფილში theme/motion/sound გადამრთველები მუშაობს მიმდინარე ბრაუზერის სესიის ფარგლებში; ახალი მონაცემები არ იგზავნება Supabase-ში.
- შენარჩუნებულია არსებული URL-ები და პროექტის სახელმწიფო/SRS/გაკვეთილის გამოთვლების ლოგიკა.

## მონაცემები და უსაფრთხოება

`js/config.js`-ში არსებული Supabase publishable key შენარჩუნებულია. 2026-11-27-ს ბაზაში განხორციელდა უსაფრთხოების და CEFR ინდექსაციის მიგრაცია `20261127211657_peera_v2_secure_admin_and_cefr.sql`. არსებული ანგარიშები, XP და ლექსიკონი შენარჩუნდა. იხილე `DEPLOYMENT-REPORT.md`.

- თუ Supabase SDK/ქსელი მიუწვდომელია, მოქმედებს ორიგინალი fallback ლოკალურ JSON ფაილებზე.
- `data/words.json` და `data/lessons.json` შეიცავს მხოლოდ ატვირთული ZIP-ის დემო მონაცემებს. რეალური Supabase ბაზა შესაძლოა მეტ ჩანაწერს შეიცავდეს.
- გრამატიკის, თამაშებისა და სასწავლო გეგმის ზოგი ღილაკი ორიგინალ პროექტში ჯერ კიდევ „მალე“-ზეა მიბმული. დიზაინის განახლება არ ნიშნავს მათ ბექენდულ ან ფუნქციურ იმპლემენტაციას.
- ამოღებულია ელფოსტით ავტომატური ადმინისტრატორის მინიჭება და საჯაროდ ხელმისაწვდომი `SECURITY DEFINER` დამხმარე ფუნქციები; RLS განახლებულია. **XP ისევ კლიენტიდან იმართება**, ხოლო SRS ჩაწერის სრული E2E ტესტი ჯერ არ ჩატარებულა.
- წინარე პროექტში არსებული `localStorage` fallback ხელუხლებელია; პროფილის ახალი ვიზუალური პარამეტრები მას არ იყენებს.

## შემოწმების ზღვარი

გაკეთდა JS სინტაქსის შემოწმება, Node.js-ზე ყველა ხედის HTML გენერაცია, JSON/PNG რესურსების შემოწმება და Chromium-ში ამ HTML-ის standalone ვიზუალური რენდერი 390px და 1280px სიგანეზე. გარემოს უსაფრთხოების შეზღუდვის გამო სრულ ინტეგრირებულ HTTP/Supabase ბრაუზერულ E2E სცენარებს ვერ გავუშვით. რეალურ დომენზე გაშვების შემდეგ საჭიროა ავტორიზაციის, SRS-ის, Supabase ჩაწერის და რეალური მოწყობილობების ტესტი.
